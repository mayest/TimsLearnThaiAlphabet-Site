Using Windows? See Windows Help and troubleshooting and download and backup guidance. The instructions below describe the Mac app.

Help with Tim’s Learn the Thai Alphabet.

This guidance applies to the current Mac application on Apple silicon. App Store distribution is being prepared. An iPad version is planned; iPad-specific instructions will be added when it is available.

Built-in Help

Choose Help → Tim’s Learn the Thai Alphabet Help in the Mac menu bar. Search the Help window or choose All Help topics. The question-mark buttons in app windows open relevant Help topics. Built-in Help is included with the app and works offline.

Common troubleshooting

No pronunciation audio
Check Settings → Game → Audio → Game Volume, then your Mac’s volume and audio output. At 0% the app is silent. Pronunciation Feedback controls automatic pronunciation; it does not disable listening prompts or manual Play. If a playback error appears, try Play again.
Start is unavailable
Read the explanation below the setup controls. The selected set may not contain enough distinct items for the grid, or may not support the selected mode. Choose a compatible set, smaller grid, or enabled Quiz question type.
A Thai character looks wrong
Compare it using Standard (Thonburi). Check Settings → Fonts for compatible installed fonts. After installing a font, use Refresh Installed Fonts.
History or reports appear empty
Check Content, Period, date range, and other filters. Some reports require enough retained completed activities. Missing evidence does not mean that your learning progress has been judged.
An import fails
Keep the original file and read the error. Use Restore Backup for a complete backup ZIP; use the category-import controls for extracted history files. Do not delete your history to clear an import error.

If a problem persists, finish your activity, quit and reopen the app, and consult Troubleshooting in built-in Help.

Backups and restoring learning history

  1. Open Settings → History and choose Back Up All Data….
  2. Save the ZIP in a location you control. Keep dated copies before replacing data or reducing history retention.
  3. To restore, choose Restore Backup…, select a ZIP created by Back Up All Data, and review the summary.
  4. Restore and Quit replaces all saved app data and settings. It does not merge two histories. The app creates a recovery backup before replacement and finishes restoring when reopened.

Finish active practice first. Backups do not restore installed fonts, app resources, previously deleted observations, or unfinished game/Quiz activities. Backups are not encrypted.

Export Complete History as ZIP… creates readable history files for analysis. A history-only export is different from a complete backup and cannot be used with Restore Backup.

If a restore cannot finish, follow the recovery screen’s instructions. Built-in Help explains Show Recovery Folder and Use Pre-Restore Recovery Backup and Quit.

Contact support

Email

Include your app version, Windows or macOS version, the activity involved, what you expected, and what happened. You may include a screenshot or the exact error message. Remove private information from screenshots and attachments. You do not need to send your learning history for an initial report.

Extract and run

  1. Download the ZIP for your PC and choose Extract All in File Explorer.
  2. Choose a folder you can write to, such as a Thai Alphabet folder in Documents. Program Files is unnecessary and may require administrator permission to copy files.
  3. Open the extracted folder and double-click ThaiAlphabet.Windows.exe. Keep every extracted file and subfolder together; the EXE cannot run by itself.

The first launch may take longer while the app checks installed Thai fonts. You can create a shortcut to the EXE for easier access.

There is no setup wizard or Apps & Features entry for these portable previews. To update, close the app and extract the next version into a new folder, then update your shortcut. To remove a preview, close it and delete only its extracted application folder and any shortcut you created.

Your settings and learning data are stored separately in %LOCALAPPDATA%\ThaiAlphabetWindows; the font cache uses %LOCALAPPDATA%\ThaiAlphabetWindowsCache. Removing the application folder does not remove these records. Before updating or replacing saved data, use Settings → History → Back Up All Data.

Windows Help and support

Built-in illustrated Help
Use the app’s Help menu or a question-mark button. The native Windows Help viewer, illustrations, and search are included and work offline. Practice Tips and the guided tour help you get started.
No audio
Open Settings → Game → Audio and use Test Audio. Check Game Volume and Windows’ selected output. Keep HDMI audio active is an optional workaround for receivers that clip short recordings; it cannot repair a disconnected Windows audio device.
A Thai character looks wrong
Compare it using Leelawadee UI, if available, and review compatible fonts in Settings → Fonts. After installing a font, close and reopen the app so it can check the updated installed-font list.
No compatible Thai font is installed
The app offers a friendly recovery screen before opening your saved data. You can download Noto Sans Thai Looped from Google Fonts and follow Microsoft’s font-installation instructions. Return to the app and choose Try Again; if necessary, close and reopen it. Fonts are never downloaded or installed automatically.
Help opens without its pages
If Windows blocked Help after a browser download, close Help and check the ZIP’s Properties for an Unblock option. If offered, apply it and extract again into a new folder. Your computer’s security policies may restrict downloaded Help.
A report or practice button is unavailable
Check the report’s filters and evidence requirements. Some reports and trouble-practice options need enough completed practice before they become available.

For help, contact support with the app version, Windows version, x64 or ARM64, and what happened. You do not need to send learning-history files for an initial report.

Backups stay on the same platform

Settings → History offers Back Up All Data and Restore Backup. Restoring a complete Windows backup replaces the destination’s saved data and settings; it does not merge histories. The app creates a recovery backup first.

Cross-platform restores are not supported. Apple backups cannot be restored on Windows, and Windows backups cannot be restored on Apple devices. History exports for analysis are not restorable backups.

Free to use, with your progress kept on your PC

No account, advertising, subscriptions, or in-app purchases. Learning history and settings stay local; they are not automatically sent to the developer. Practice, recordings, charts, and Help work offline.
